# Yosef Mehari — Full-Stack Developer Portfolio

Personal portfolio showcasing full-stack web applications, technical architecture, and software engineering capabilities.

## 🚀 Live Showcase & Highlights

- **Live URL**: [portfolio](https://yosefmehari.github.io/portfolio/) (or open `index.html`)
- **Key Stack**: Next.js 16, React 19, TypeScript, Node.js, Express, Prisma ORM, PostgreSQL, Tailwind CSS
- **Featured Projects**:
  - **[QR-CAFE](https://github.com/yosefmehari/QR-CAFE)**: Modern full-stack restaurant ordering & management platform with customer QR ordering, Prisma ORM, PostgreSQL, and multi-role dashboards (Admin, Chef, Waiter, Delivery).
  - **[NeuMart](https://github.com/yosefmehari/NeuMart)** ([Live Demo](https://neu-mart.vercel.app)): Modern e-commerce storefront with dynamic catalogs, cart management, and responsive UI.
  - **[LaunchFlow](https://github.com/yosefmehari/LaunchFlow)**: Cloud workflow automation and developer orchestration pipeline.
  - **[QETABET](https://github.com/yosefmehari/QETABET)**: Full-stack productivity & record-keeping system with Prisma & PostgreSQL.
  - **[SuperMarket POS & Store](https://github.com/yosefmehari/super-market)**: Interactive supermarket billing and inventory management application.
  - **[Building the Mind](https://github.com/yosefmehari/building-the-mind)**: Technical documentation and knowledge platform.
  - **[Shopping Clothes](https://github.com/yosefmehari/shopping-clothes)**: Apparel retail web application.

## 🛠️ Features

- **Responsive & Modern UI**: Tailored with Space Grotesk, Plus Jakarta Sans, and JetBrains Mono typography.
- **Mobile Drawer Navigation**: Animated hamburger menu toggle with responsive drawer and smooth touch interaction.
- **Project Filter Pills**: Dynamic client-side filtering by category (All, Full-Stack, E-Commerce, Systems).
- **Interactive Ambient Glow**: 60fps cursor follower with `requestAnimationFrame` and touch-screen safety.
- **Direct Contact & Copy Feature**: 1-click email copy with visual confirmation and interactive mail-client launcher.
